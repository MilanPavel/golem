# Roadmap

Where golem is going lives in GitHub issues, not in a file ([ADR-042](adr/042-roadmap-in-issues.md)). This page only says where to look, so it cannot go out of date.

- **The board:** [Project 1](https://github.com/users/MilanPavel/projects/1) shows every phase, step, and ticket, grouped by status. Filter by the Phase field to see one phase.
- **The long view:** [the vision](vision.md) says what golem becomes, and why, with no dates.
- **What exists today:** [the architecture](architecture.md) and the [ADRs](adr/README.md).
